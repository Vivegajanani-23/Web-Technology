# 🌐 Web Technology

A comprehensive collection of **HTML, CSS, and JavaScript programs and mini-projects** developed to strengthen practical web development skills and understand core front-end concepts.

## 👩‍💻 About This Repository

This repository contains my learning journey in **Web Technology**, including fundamental concepts, practical examples, and mini-projects using HTML, CSS, and JavaScript.

The projects are organized topic-wise to make the repository easy to understand, explore, and use for learning and practice.

## 🚀 Technologies Used

* **HTML5** – Structure, forms, tables, multimedia, semantic elements, and iframes
* **CSS3** – Selectors, Flexbox, Grid, animations, transitions, positioning, and responsive layouts
* **JavaScript** – DOM manipulation, events, loops, arrays, objects, Local Storage, Promises, Async/Await, and Fetch API
